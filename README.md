# 대한영양사협회 입법 모니터링 자동화 시스템

국회에 발의된 법률안과 정부 입법예고 중, 지정한 키워드(예: "영양사", "급식")가 포함된
새 입법을 자동으로 찾아서 웹사이트 목록으로 정리해주는 시스템입니다.

- 국회 발의 법률안: 공공데이터포털 국회 API
- 정부 입법예고: 공공데이터포털 법제처 API
- 실행: GitHub Actions (무료, 6시간마다 자동 실행)
- 결과 확인: GitHub Pages (무료 웹사이트, 예: `https://내아이디.github.io/legis-monitor/`)

전부 무료이며, 서버를 직접 관리할 필요가 없습니다. 아래 순서대로 그대로 따라 하시면 됩니다.

---

## 전체 흐름 한눈에 보기

1. GitHub(코드 저장 및 자동 실행 서비스)에 가입하고, 이 프로젝트 파일을 올린다
2. 공공데이터포털에서 API 이용 신청을 하고 "인증키"를 받는다
3. 인증키를 GitHub에 비밀번호처럼 등록한다 (Secrets)
4. GitHub Pages를 켜서 결과가 웹사이트로 보이게 한다
5. 6시간마다 자동으로 새 입법을 확인 → 키워드가 맞으면 웹사이트에 추가

---

## 1단계. GitHub 계정 만들고 저장소(프로젝트 공간) 만들기

1. https://github.com 접속 → 우측 상단 **Sign up** 으로 무료 가입
2. 로그인 후 우측 상단 **+** 버튼 → **New repository** 클릭
3. Repository name에 `legis-monitor` 입력 (다른 이름도 가능)
4. Public(공개)으로 두고 **Create repository** 클릭

## 2단계. 이 프로젝트 파일 업로드

1. 방금 만든 저장소 화면에서 **Add file → Upload files** 클릭
2. 제가 드린 압축 파일(zip)을 풀어서 나온 **모든 파일과 폴더**를 통째로 끌어다 놓기
   (`monitor.py`, `requirements.txt`, `README.md`, `.github` 폴더, `docs` 폴더 전부 포함되어야 합니다)
   - `.github` 폴더처럼 점(.)으로 시작하는 폴더도 컴퓨터에서 보이도록,
     Mac은 `Cmd+Shift+.`, Windows는 탐색기의 "숨긴 항목 보기"를 켜두면 편합니다.
3. 하단의 **Commit changes** 클릭 → 업로드 완료

## 3단계. 공공데이터포털 API 인증키 발급받기

두 개의 API를 각각 신청해야 하지만, **인증키는 하나만 발급받으면 공용으로 사용**할 수 있습니다.

1. https://www.data.go.kr 접속 후 회원가입/로그인
2. 검색창에 **"국회사무처 의안정보"** 검색 → `국회사무처_의안정보` (BillInfoService2) 데이터 클릭
   → **활용신청** 버튼 클릭 → 활용 목적 간단히 작성 (예: "협회 정책 업무 참고용 모니터링") → 신청
3. 검색창에 **"법제처 정부입법예고"** 검색 → `법제처_정부입법예고` 데이터 클릭
   → 마찬가지로 **활용신청**
4. 두 API 모두 대부분 **자동 승인**(즉시 또는 1일 이내)됩니다.
5. 마이페이지 → **오픈API → 개발계정** 메뉴에서 **일반 인증키(Encoding)** 값을 복사해둡니다.
   (이 문자열이 앞으로 쓸 "인증키"입니다)

> 💡 승인 후 각 API 상세페이지에는 "미리보기"라는 기능이 있어서, 인증키만 넣으면
> 브라우저에서 바로 실제 응답 결과(JSON)를 눈으로 확인할 수 있습니다.
> 나중에 "문제 해결" 섹션에서 이 기능을 사용합니다.

## 4단계. 인증키를 GitHub에 안전하게 등록하기 (Secrets)

인증키를 코드에 직접 적으면 안 되고, GitHub의 "비밀 보관함"에 등록합니다.

1. 저장소 화면 상단 **Settings** 클릭
2. 왼쪽 메뉴 **Secrets and variables → Actions** 클릭
3. **New repository secret** 클릭
4. Name: `DATA_GO_KR_KEY`
5. Secret: 3단계에서 복사한 인증키 붙여넣기
6. **Add secret** 클릭

## 5단계. GitHub Pages 켜기 (결과를 보여줄 웹사이트)

1. 저장소 **Settings → Pages** 메뉴로 이동
2. **Branch** 항목에서 `main` 브랜치, 폴더는 `/docs` 선택 후 **Save**
3. 몇 분 후 상단에 `https://내아이디.github.io/legis-monitor/` 같은 주소가 표시됩니다.
   이 주소가 앞으로 계속 확인할 **모니터링 웹사이트 주소**입니다. 즐겨찾기 해두세요.

## 6단계. 자동 실행 테스트해보기

1. 저장소 상단 **Actions** 탭 클릭
2. 왼쪽에서 **"입법 모니터링 자동 실행"** 클릭
3. 오른쪽 **Run workflow → Run workflow** 버튼 클릭 (수동으로 1회 즉시 실행)
4. 1~2분 후 초록색 체크(✅)가 뜨면 성공. 빨간 x가 뜨면 "문제 해결" 섹션 참고
5. 5단계에서 확인한 웹사이트 주소로 접속해서 결과 확인

이후로는 **6시간마다 자동으로** 새로 실행되며, 새로 발견된 입법은 "NEW" 표시와 함께 목록에 추가됩니다.

## 키워드(감시 단어) 수정하는 방법 (비전공자도 가능)

1. 저장소에서 `monitor.py` 파일 클릭 → 오른쪽 위 연필 아이콘(✏️ Edit) 클릭
2. 아래 부분을 찾아서

```python
KEYWORDS = [
    "영양사", "영양", "급식", "학교급식", "국민영양관리법",
    "식생활", "영양교육", "영양표시", "식품위생",
]
```

원하는 단어로 자유롭게 추가/삭제 (따옴표와 쉼표 형식만 유지)
3. 하단 **Commit changes** 클릭 → 다음 자동 실행부터 새 키워드로 적용

## 실행 주기(몇 시간마다 확인할지) 바꾸는 방법

`.github/workflows/monitor.yml` 파일에서 아래 줄을 수정합니다.

```yaml
- cron: "0 0,6,12,18 * * *"   # 6시간마다 (0시,6시,12시,18시 UTC)
```

예: 하루 1번(한국시간 오전 9시경)만 원하면 `- cron: "0 0 * * *"` 로 변경

## 문제 해결 (자주 발생하는 상황)

### Actions 실행이 빨간 x(실패)로 뜰 때
1. Actions 탭 → 실패한 실행 클릭 → 로그를 펼쳐서 에러 메시지 확인
2. `[국회 API 오류]` 또는 `[입법예고 API 오류]` 로 시작하는 메시지가 보이면 인증키/네트워크 문제일 가능성이 큽니다.
   → Settings → Secrets에 `DATA_GO_KR_KEY`가 정확히 등록되어 있는지 다시 확인하세요.

### "예상과 다른 응답 구조입니다" 라는 메시지가 뜰 때
공공데이터포털은 API마다 응답 항목 이름(필드명)이 살짝씩 다릅니다. 이럴 땐:
1. data.go.kr에서 해당 API 상세페이지의 **미리보기** 기능으로 실제 응답을 확인
2. `monitor.py` 안에서 `## 여기를 수정하세요 2)` 또는 `3)` 이라고 적힌 부분을 찾아서
   `item.get("billName")` 처럼 되어있는 부분의 따옴표 안 이름을,
   실제 응답에서 본 이름으로 바꿔주면 됩니다.
   (예: 실제 필드가 `BILL_NM` 이라면 `item.get("billName")` → `item.get("BILL_NM")`)

이 부분이 어렵게 느껴지시면, 미리보기에서 나온 실제 JSON 결과를 저에게 보여주시면
정확한 필드명으로 코드를 맞춰드릴 수 있습니다.

### 웹사이트에 아무것도 안 뜰 때
정상입니다 — 아직 키워드와 일치하는 새 입법이 없다는 뜻입니다.
키워드가 잘 잡히는지 테스트하려면 KEYWORDS에 "법률"처럼 아주 흔한 단어를 임시로 추가해서
확인해본 뒤 다시 원래대로 되돌리면 됩니다.
